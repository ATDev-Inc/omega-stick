# Getting help

Omega Stick is open-source firmware for a configurable computer and gaming input
peripheral for accessibility. It is not a medical device, and this repository is
not a support service. Questions about a person's medical needs, care,
or whether an input device suits them belong with a clinician or an
assistive-technology professional. Please do not post personal health information
in public issues or discussions.

## Where to go

- **Questions about using or building it:** use
  [GitHub Discussions](https://github.com/ATDev-Inc/omega-stick/discussions).
- **Bugs and feature requests:** use the
  [issue forms](https://github.com/ATDev-Inc/omega-stick/issues/new/choose).
- **Accessibility feedback** (for example, the calibration console or the
  documentation being hard to use): use the
  [accessibility feedback form](https://github.com/ATDev-Inc/omega-stick/issues/new?template=accessibility_feedback.yml).
- **Security issues:** follow [SECURITY.md](SECURITY.md) and report privately. Do
  not open a public issue.

## Before you ask

Check the [documentation](docs/) and existing issues and discussions first. For a
bug, include the firmware version (shown in the calibration console), what you
did, and what you expected.
