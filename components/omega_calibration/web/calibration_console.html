    Input mode

    The device saves its settings and restarts to apply the new mode, so this console will disconnect; reconnect afterwards.

    Recalibration

    Runs the full interactive center + range calibration sequence on the device (a stick with no usable calibration waits for this). This blocks mouse/XAC output for the duration and walks you through moving the stick via printed prompts. Connect over Web Serial (not WebUSB) to see those prompts in the console log below. Manual deadzone overrides, nudge tuning, and input mode are left as-is.
