Input mode

The device saves its settings and restarts to apply the new mode, so this console will disconnect; reconnect afterwards.

Recalibration

Re-runs the full interactive center + range calibration sequence on the device (the same one that runs on a fresh boot). This blocks mouse/XAC output for the duration and walks you through moving the stick via printed prompts. Connect over Web Serial (not WebUSB) to see those prompts in the console log below. Manual deadzone overrides, nudge tuning, and input mode are left as-is.

Console / log

Speaks a module-5 extension of the espp OT framing shared with the coredump and OTA consoles (magic "OT" + flags + module + type + len + payload + CRC-32; see this page's source comment for the full spec). Firmware updates (build/omega_stick.bin) are handled in the "Firmware update" section above; see docs/firmware-updates.md for the rollback and versioning rules. Everything here runs locally in your browser.
