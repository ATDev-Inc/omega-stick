Input mode

Applies live and takes effect immediately (may re-enumerate the USB HID device).

Recalibration

Re-runs the full interactive center + range calibration sequence on the device (the same one that runs on a fresh boot). This blocks mouse/XAC output for the duration and walks you through moving the stick via printed prompts — connect over Web Serial (not WebUSB) to see those prompts in the console log below. Manual deadzone overrides, nudge tuning, and input mode are left as-is.

Console / log

Speaks a module-5 extension of the espp OT framing shared with the coredump and OTA consoles (magic "OT" + flags + module + type + len + payload + CRC-32; see this page's source comment for the full spec). Firmware flashing (.elf) is handled by the separate OTA console — see ota_console.html alongside this page. Everything here runs locally in your browser.
